# Patrick Alituha Website

Starter personal brand and business showcase website built with HTML, Bootstrap 5.3.8 and vanilla JavaScript.

## Pages
- `index.html` — homepage with hero, current products carousel, about preview, projects and services
- `about.html` — personal story starter
- `projects.html` — project showcase starter
- `services.html` — service offering starter
- `contact.html` — front-end validated contact form starter

## Run locally
You can open `index.html` directly, or run a simple local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
